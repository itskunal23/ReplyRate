# Agent operating model (spec only)

The aim is a business one person can run. Agents do the repetitive work, and the founder keeps judgment and approval. Nothing here is built.

| Agent | Does | Human gate |
|---|---|---|
| Research | Sourced facts for Reels, competitor changes | Founder checks any claim before it is public |
| Script | Drafts Reels in the three formats | Founder picks and edits |
| Data quality | Flags duplicates, fraud patterns, thin samples | Founder decides removals |
| Index | Drafts the monthly Ghost Index from aggregates | Founder approves publishing |
| Support | Drafts replies, processes guarantee refunds under a limit | Above the limit, founder approves |
| Finance | Records costs and revenue | Any new spend needs approval |

Every paid API call is recorded. Each gated action leaves an approval record. Both are patterns from the archived stack worth keeping.
