## Evidence labels

| Label | Meaning |

| [V] | Verified: published by an outside source, linked or named |
| [C] | Calculated from stated inputs |
| [A] | Assumption used in a model |
| [H] | Hypothesis, not yet tested |

If a claim has no label, treat it as opinion.
