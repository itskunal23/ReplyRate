# Prototype

`replyrate-ui/index.html` is one self-contained page. Open it in any browser.

- It is a design artifact, not the product. No data leaves the page, and nothing is charged.
- All companies and numbers are invented. Pricing and path-to-revenue figures come from the [financial model](../docs/03-financials/FINANCIAL_MODEL.md).
- The charts use illustrative curves. See the [spec](../docs/00-thesis/PRODUCT_SPEC.md#4-the-math) for what production needs.
